# 批量加水印工具

一个用于批量添加水印的图片处理工具。

## 功能特性

- 批量添加水印到图片
- 多种图片格式支持 (JPG, PNG, BMP等)
- 可调节水印透明度
- 统一输出图片宽度
- 实时预览效果
- AI超分辨率放大（小图放大时自动提升清晰度）

## 使用方法

### 运行程序

```bash
uv run python watermark_gui.py
```

### 构建可执行文件

```bash
uv run python build.py --pyinstaller
```

## 系统要求

- Windows 10/11
- Python 3.13+
