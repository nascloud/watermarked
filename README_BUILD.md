## 主要功能

### ✨ 核心功能
- **批量加水印**: 一次处理多张图片
- **实时预览**: 所见即所得的效果预览
- **多种格式**: 支持 JPG、PNG、BMP 等常见格式
- **透明度调节**: 可调节水印的透明度

### 🎯 新增优化
- **智能缩放**: 自动选择最佳图片缩放算法
- **质量提升**: 大幅提升图片放大和缩小的质量
- **实时响应**: 所有设置变化都会立即更新预览
- **事件修复**: 修复了所有GUI控件的响应问题

### 🔧 技术特性
- **分步处理**: 大幅缩放时使用分步处理保持质量
- **多级锐化**: 应用预锐化、分步锐化和后锐化
- **自适应算法**: 根据缩放比例自动选择最佳策略
- **细节保持**: 更好地保持原图细节和边缘清晰度

## 系统要求

- **操作系统**: Windows 10/11
- **内存**: 建议 4GB 以上
- **存储**: 约 50MB 可用空间

## 故障排除

### 如果程序无法启动
1. 确保您的Windows系统是64位版本
2. 尝试以管理员身份运行
3. 检查是否被杀毒软件误报

### 如果处理速度较慢
1. 这是正常现象，新的质量优化算法需要更多计算时间
2. 大幅缩放时处理时间会明显增加（约3-9倍）
3. 但质量提升是显著的，特别值得等待

### 如果遇到其他问题
1. 检查输入图片格式是否支持
2. 确保有足够的磁盘空间保存输出文件
3. 检查输出文件夹是否有写入权限
